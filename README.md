# The Dental House — Kluang

A custom, responsive **website concept** for Klinik Pergigian The Dental House and Dr Dayana Hazwani Ahmad, designed for review before any official launch.

## Preview deployment (GitHub Pages)

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. Once GitHub finishes publishing, visit **https://shukritobi.github.io/The-dental-house.my/**.

The site is static HTML/CSS/JavaScript, so there is **no build command** and **no server or database**.

## Features

- Editorial sage, cream and coral visual identity, custom dental illustration, responsive layout.
- Dr Dayana's verified biography and portrait sourced from the clinic's official website.
- Treatment catalogue with category filters and indicative published price ranges.
- Responsive mobile navigation, FAQs, contact/location links, and a WhatsApp appointment enquiry form.
- Appointment form prepares a message sent directly to the Kluang clinic's public number (+60 11-1060 9594); **this is not a confirmed appointment**.
- No visitor data is collected or stored by this demo.

## Important review notes

- This is a **concept**, not the clinic's official deployed website. It uses `noindex,nofollow` until client approval.
- Content, prices, portrait rights and service availability must be checked with the clinic prior to production deployment.
- The portrait currently loads from the clinic's existing site; self-host an approved original asset for production.
- The original clinic domain remains untouched.
